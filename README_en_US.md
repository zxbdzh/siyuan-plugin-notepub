# NotePub for SiYuan

[简体中文](./README.md)

NotePub is a publishing plugin for SiYuan that sends documents, document trees, or entire notebooks to a self-hosted NotePub site, making notes available as a blog or documentation site.

## Features

- Publish a document, a document tree with descendants, or an entire notebook
- Synchronize Markdown, document hierarchy, and local attachments
- Choose between blog and documentation layouts
- Create public, private, or password-protected shares
- Manage published content, access policies, and share links
- Automatically synchronize changes to previously published content
- Encrypt saved share passwords when operating-system secure storage is available
